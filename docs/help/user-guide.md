# AI PDF Studio: Beginner User Guide

## 1. Create your first document

Open Templates, search for the kind of document you need, and select a card to inspect its structure. Choose a visual theme separately, then create the document. Use New Blank Document if you do not want a template. Templates contain editable drafting placeholders. Replace them with verified facts before execution.

## 2. Use the AI assistant

The assistant accepts ordinary language. Tell it the desired outcome and what must not change. For example: "Add a short confidentiality section after the scope section. Do not rewrite the existing payment terms." Review its execution summary and inspect the resulting document. If a request could change a material legal or financial term, provide the exact intended value.

## 3. Edit text and structure

Edit section headings, body text, and clause wording in the editor. Use the document outline to navigate. Right-click a section, text selection, or blank document area for context actions. Use Undo and Redo to reverse recent edits.

## 4. Add signatures and custom fields

Select labeled text such as Date: ______ before opening Insert > Signature to prefill editable fields. If nothing is selected, add the labels you need. Change each field's type to Text, Date, or Signature, adjust its line length, and remove any fields you do not need. Choose a printable, typed, or drawn signature method. A line will be fitted to the printable page width when exported.

## 5. Customize appearance

Open Format > Document Design and choose a preset or customize typography, colors, section surfaces, tables, and cover styling. The template's wording and visual theme are independent. Page size, orientation, margins, headers, footers, page numbers, and watermarks can be managed separately.

## 6. Preview and export

Open PDF Preview before distributing the document. Check page breaks, line wrapping, tables, images, signature panels, page numbers, and all names, dates, and amounts. Export the PDF or use the print workflow. JSON, Markdown, and plain-text exports provide portable backups.

## 7. Review responsibly

AI-generated content is a draft. Verify party identities, payment amounts, dates, deliverables, ownership, territory, term, governing law, and negotiated terms. Templates are not legal advice. Obtain qualified review where the transaction or jurisdiction requires it. For redaction, verify the final exported PDF rather than relying only on visual concealment.

## 8. Shortcuts

- Ctrl/Cmd + Z: Undo
- Ctrl/Cmd + Shift + Z or Ctrl + Y: Redo
- Ctrl/Cmd + F: Find
- Ctrl/Cmd + H: Find and replace
- Ctrl/Cmd + P: PDF preview
- Ctrl/Cmd + S: Export document JSON
- Ctrl/Cmd + B / I / U: Bold / italic / underline
- Ctrl/Cmd + K: Command palette
- Esc: Close active modal/menu
