# AI PDF Studio: Beginner User Guide

## Create a document
Open Templates, search by document name or category, inspect the selected template, choose a visual theme, and create the document. The template content and theme are independent. Use New Blank Document to start without a template.

## Use the AI assistant
Describe the desired outcome in everyday language. State what must change and what must remain untouched. Example: "Add a concise confidentiality section after Scope. Do not change the payment terms." Review the AI operation summary and inspect the document after each edit. Provide exact values for material business terms.

## Edit text and structure
Edit the title, cover details, section headings, body text, and clause text in the editor. The metadata row beneath the document title also has editable Version, Document Type, Date, and Author labels and values. Delete any field with its trash icon, restore it with Add field, and the layout will collapse when fields are removed. PDF exports preserve the displayed metadata. Use the outline to navigate. Right-click selected text, a section, a clause, an image, a table, a signature block, or blank document canvas to see context-specific actions. Use Undo and Redo to reverse recent changes.

## Add signatures and custom fields
Select labeled text such as Date: ______ before opening Insert > Signature to prefill editable fields. If nothing is selected, rename, add, remove, and change field types in the customization panel. Each field has an independent line-length setting. Choose printable, typed, or drawn signature mode. The PDF renderer fits long lines to the printable page width.

## Customize appearance
Open Format > Document Design. Choose a preset or customize typography, colors, section styling, tables, cover treatment, and page furniture. Page size, orientation, margins, headers, footers, page numbers, and watermarks are separate from the document wording.

## Preview and export
Open PDF Preview before distributing the document. Inspect pagination, line wrapping, tables, images, signature panels, page numbers, names, dates, and amounts. Export PDF or use the print workflow. JSON, Markdown, and plain-text exports provide portable backups.

## Review responsibly
AI-generated content is a draft. Verify party identities, payment amounts, dates, deliverables, ownership, territory, term, governing law, and negotiated terms. Templates are not legal advice. Obtain qualified review where the transaction or jurisdiction requires it. For redaction, inspect the exported PDF rather than relying only on visual concealment.

## Keyboard shortcuts
- Ctrl/Cmd + Z: Undo
- Ctrl/Cmd + Shift + Z or Ctrl + Y: Redo
- Ctrl/Cmd + F: Find
- Ctrl/Cmd + H: Find and replace
- Ctrl/Cmd + P: PDF preview
- Ctrl/Cmd + S: Export document JSON
- Ctrl/Cmd + B / I / U: Bold / italic / underline
- Ctrl/Cmd + K: Command palette
- Esc: Close active modal/menu
